# GitHub Explorer

Приложение для поиска пользователей GitHub и просмотра информации об их профилях и репозиториях.

## Возможности

- Поиск пользователей GitHub по имени.
- Просмотр основной информации о пользователе.
- Просмотр списка репозиториев пользователя.
- Фильтрация и сортировка репозиториев.
- Просмотр подробной информации о выбранном репозитории.
- Просмотр используемых в репозитории языков.
- Отображение README репозитория.

## Технологии

- React
- TypeScript
- Vite
- React Router
- CSS Modules
- GitHub REST API
- Vitest
- React Testing Library

## Запуск проекта

1. Клонируйте репозиторий:

```bash
git clone https://github.com/katetugova/github-explorer.git
```

2. Перейдите в папку проекта:

```bash
cd github-explorer
```

3. Установите зависимости:

```bash
npm install
```

4. Запустите проект в режиме разработки:

```bash
npm run dev
```

После запуска приложение будет доступно по адресу, указанному Vite в терминале.
